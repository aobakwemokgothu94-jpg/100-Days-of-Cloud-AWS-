Welcome to my **100 Days of Cloud (AWS)** repository! This is a hands-on learning challenge structured to build and solidify practical Amazon Web Services (AWS) skills over 100 consecutive days. 

Through daily tasks, real-world projects, and hands-on lab exercises, this challenge covers foundational cloud architecture, networking, compute, storage, security, serverless computing, and Infrastructure as Code (IaC).

---

## 🎯 Project Objectives

- **Hands-on Practice:** Build, configure, and troubleshoot AWS infrastructure components daily.
- **Architectural Mastery:** Understand core AWS services, cloud security best practices, and cost-efficient designs.
- **Automation & IaC:** Implement deployment automation using tools like Terraform, CloudFormation, and Ansible.
- **Documentation:** Track progress, code samples, and key architecture diagrams in a structured format.

---

## 🛠️ Key Topics & Technologies

- **Compute & Containers:** EC2, Lambda, ECS, EKS, Docker
- **Networking & Content Delivery:** VPC, Subnets, Route Table, Internet Gateway, CloudFront, Route 53
- **Storage & Databases:** S3, EBS, EFS, RDS, DynamoDB
- **Security & Identity:** IAM, KMS, Security Groups, NACLs, Secrets Manager
- **Management & Governance:** CloudWatch, CloudTrail, AWS CLI
- **Infrastructure as Code (IaC):** Terraform, AWS CloudFormation
